# Pothole Reporter

A web application where citizens can report potholes and track their reports.
Built as a college mini project.

## Features
- Sign up, sign in and logout with secure sessions
- Report a pothole with location, road type, severity, description and photo
- View your own reports, filter by severity, mark as fixed or delete
- Passwords stored as bcrypt hashes
- Form validation on both the front-end and the back-end

## Tech Stack
HTML, CSS, JavaScript, Node.js, Express.js, MongoDB, Mongoose,
express-session, bcryptjs

## How to Run
1. Install Node.js and MongoDB, and make sure MongoDB is running
2. Run `npm install`
3. Run `node serverfile.js`
4. Open http://localhost:3000 in your browser
